Frequently asked questions

Answers to your most common queries

How can I upload files to the site?

▸

To upload files, log in to your account, then go to the file upload page. There, you can select files from your device and click the Upload button. Make sure that the files meet the specified standards.

What file types are allowed?

▸

The site accepts many file types including:

  • PNG
  • PDF
  • DOCX
  • JPG

File size must not exceed 10MB per file. Make sure to check the list of allowed files before uploading.

How can I get help if I encounter a problem?

▸

You can contact technical support via email TaskVault1@gmail.com or use the contact form on the help page.
